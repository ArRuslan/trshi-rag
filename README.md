# RAG-система довідки зі стандартної бібліотеки Python

Офлайн-помічник розробника зі стандартної бібліотеки Python: локальна RAG-система, що відповідає на запитання (українською або англійською), виключно на основі офіційної документації Python 3, і обов'язково цитує розділ-джерело.

## Сценарій

- **Цільовий користувач:** розробник Python, що працює без швидкого доступу до `docs.python.org`, пам'ятає поведінку приблизно, але не точні імена/параметри/синтаксис/деталі.
- **Гарна відповідь:** 3–8 речень (+короткий приклад коду), фактично точна для індексованої версії Python, із посиланням на розділ документації.
- **Погана відповідь:** вигадані факти, без джерела, змішування версій Python.

## Технологічний стек
