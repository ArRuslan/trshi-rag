## 3. Чанкування

Стратегія: чанкування фіксованого розміру за токенами моделі ембедингів (`google/embeddinggemma-300m`) з перекриттям ~10%.

| Параметр                                | Значення                                                                                         |
|-----------------------------------------|--------------------------------------------------------------------------------------------------|
| Soft limit                              | 512 токенів                                                                                      |
| Hard limit                              | 1024 токени                                                                                      |
| Перекриття                              | ~10% довжини чанка                                                                               |
| Розмір чанка (токени): med / avg / max  | 110 / 168.5 / 801                                                                                |
| Розмір чанка (слова): med / avg / max   | 58 / 94.8 / 469                                                                                  |
| Розмір чанка (символи): med / avg / max | 431 / 667.6 / 2 968                                                                              |
| Розподіл за токенами                    | ≤ 200: 74,4 %; 201–500: 17,6 %; 501–800: 8,0 %; > 800: 1 чанк (див. обмеження 8)                 |
| Текст чанка                             | метазаголовок (`File`, `Section`, `Module`, `Class`, `Function`, `Signature` тощо) + текст чанка |

Кожен чанк зберігає: ідентифікатор документа-джерела, назву розділу або сигнатуру, структуровані метадані символа API,
порядковий номер чанка в межах компонента (з нуля), кількість чанків компонента, розмір у токенах та стабільний глобальний ідентифікатор.
